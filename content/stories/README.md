# Client stories (homepage §4.4)

One markdown file per story. A story only appears on the site when `consent: true` (written permission from the client is on file). Never invent or embellish stories.

```yaml
---
goal: lower-payments        # lower-payments | first-home | retirement-equity | self-employed
title: "How the Garcias cut their payment by $600"
consent: true
consentDate: 2026-10-01
image: /stories/garcia.jpg   # optional, with client permission
---
Two to four sentences in the client's own words (edited lightly).
```
